HARINI SEENUVASAN - PORTFOLIO

FILES
- index.html : Portfolio page structure
- style.css  : Custom styling and responsive layout
- script.js  : Typing effect, scroll reveal, navigation and back-to-top

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Internet is required for Bootstrap, Bootstrap Icons and Google Fonts CDN links.
